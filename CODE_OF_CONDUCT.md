# Code of conduct

tutti follows the [Rust Code of Conduct](https://www.rust-lang.org/policies/code-of-conduct).
We hope everyone who takes part, in issues, pull requests or anywhere else the
project lives, finds it a friendly and welcoming place.

If something happens that you would like the maintainer to know about, please
reach out privately to [PoHsuanLai](https://github.com/PoHsuanLai).
