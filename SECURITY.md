# Security policy

tutti has no release yet, so a fix lands on `main` only.

Report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/tutti-audio/tutti/security/advisories/new),
not in a public issue. Include what is affected, how to reproduce it and what
it lets an attacker do.

A hosted plugin is untrusted code. A plugin hosted out of process that crashes,
hangs or misbehaves in a way that reaches the host process is in scope.
