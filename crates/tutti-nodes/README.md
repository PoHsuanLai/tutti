# tutti-nodes

This crate is the set of built-in audio effects and utilities for tutti: filters, delays, compressors, reverb-style and modulation effects, LFOs, mixers, automation and convolution.

Each one is a building block you place in a tutti audio graph. It depends on tutti's graph and several other crates, so most people will use it through the `tutti` crate. If you only want the underlying algorithms, see `tutti-dsp`.

This crate is part of [tutti](https://github.com/PoHsuanLai/tutti), a real-time audio engine for Rust.
