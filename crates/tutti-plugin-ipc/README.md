# tutti-plugin-ipc

The communication layer between an application and its plugin helper process: the messages they exchange, the shared audio buffer, and the code that starts the helper and talks to it.

It is an internal building block. Most people will use it through the `tutti` or `tutti-plugin` crate rather than directly.

This crate is part of [tutti](https://github.com/tutti-audio/tutti), a real-time audio engine for Rust.
