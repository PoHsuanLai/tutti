# tutti-polysynth

This crate is a polyphonic synthesizer: oscillators into a filter and envelope, with unison, portamento, alternative tunings and per-note expression (MPE and MIDI 2.0).

It is a node you add to a tutti audio graph and drive with MIDI. It depends on several other tutti crates, so most people will use it through the `tutti` crate.

This crate is part of [tutti](https://github.com/tutti-audio/tutti), a real-time audio engine for Rust.
