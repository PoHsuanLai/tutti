# tutti-types

Shared building blocks for audio code: numbers with units (hertz, decibels, beats, tempo), channel layouts, interleaved buffers, and simple traits for streams of audio.

It has no dependency on the rest of tutti, so you can use it on its own, for example to implement an audio source or sink. Most other tutti crates are built on it.

This crate is part of [tutti](https://github.com/PoHsuanLai/tutti), a real-time audio engine for Rust.
