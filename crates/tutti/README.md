# tutti

tutti is a real-time audio engine for Rust, meant as a base for building a digital audio workstation or other audio software.

This crate is the one most people add. It brings the separate parts of tutti together behind one dependency, and cargo features choose which ones you get, such as sound devices, audio file formats, MIDI, built-in instruments and effects, plugin hosting, and offline export.
