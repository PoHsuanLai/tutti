# AudioUnit v2 spec inventory, from the AudioToolbox surface (AudioComponent.h,
# AUComponent.h, AudioUnitProperties.h, MusicDevice.h, AudioOutputUnit.h,
# AudioUnitUtilities.h). The ids, selector numbers, property numbers, bit positions
# and scopes were checked against the macOS 27.2 SDK AudioToolbox headers
# (`xcrun --show-sdk-version`): the headers ship with macOS only and are not in the
# repo, so `cargo xtask check-conformance` cannot re-check them; whoever changes
# this file re-checks against the SDK. Paraphrases are in our own words; facts are
# numbers the headers declare: sel = the dispatch selector, prop = the property
# number, bit = the bit position of a flag, mask = a bit mask or a flag value. The
# scope of use is in the paraphrase. Inter-app audio items (iOS only) and the
# AUAudioUnit (v3) API are out of this inventory.
#
# Columns: id | side | maturity | kind | section | paraphrase | facts | na-kind | cite
#
# Ids (side plugin: the audio unit implements it; host: the host supplies it;
# core: both sides name it):
#   au.select.<name>      a C entry point of the audio unit (AudioComponent*,
#                         AudioUnit*, AudioOutputUnit*, AUEventListener*, AUParameter*)
#   au.prop.<name>        kAudioUnitProperty_<name>
#   au.render.<flag>      kAudioUnitRenderAction_<flag>
#   au.param.event.<k>    kParameterEvent_<k> of AudioUnitScheduleParameters
#   au.param.flag.<k>     kAudioUnitParameterFlag_<k>
#   au.host.<cb>          a HostCallbackInfo member
#   au.midi.<fn>          a MusicDevice entry point
# na-kind deprecated rows cite the header that marks the item deprecated.
