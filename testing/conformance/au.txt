# AudioUnit v2 spec inventory. Hand-written from the AudioToolbox surface
# (AudioComponent.h, AudioUnit.h, AudioUnitProperties.h, AUComponent.h,
# MusicDevice.h, AudioToolbox/AudioUnitUtilities.h): the headers ship with macOS
# only and are not in the repo, so nothing compares this file to a source and
# review is the check. The seed names were cross-read with tutti-au-ffi only as a
# checklist; what exists is what Apple's headers declare. Paraphrases are in our
# own words; prop = the property's number, the scope of use is in the paraphrase.
#
# Columns: id | side | maturity | kind | section | paraphrase | facts | na-kind | cite
#
# Ids (side plugin: the audio unit implements it; host: the host supplies it;
# core: both sides name it):
#   au.select.<name>      a C entry point of the audio unit (AudioComponent*,
#                         AudioUnit*, AudioOutputUnit*, AUEventListener*, AUParameter*)
#   au.prop.<name>        kAudioUnitProperty_<name>
#   au.render.<flag>      kAudioUnitRenderAction_<flag>
#   au.param.event.<k>    kParameterEvent_<k> of AudioUnitScheduleParameters
#   au.param.flag.<k>     kAudioUnitParameterFlag_<k>
#   au.host.<cb>          a HostCallbackInfo member, or a kAUHostTransportState_ flag
#   au.midi.<fn>          a MusicDevice entry point
# na-kind deprecated rows cite the header that marks the item deprecated.
