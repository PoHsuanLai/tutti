# SoundFont 2.04 spec inventory. The spec text is not in the repo (its license
# allows internal use only) and nothing of it is quoted here: ids, section
# numbers, enumerator values, defaults, ranges and sizes are facts; every
# paraphrase is in our own words.
#
# How the rows are checked (`cargo xtask check-conformance`):
#  - Extracted rows are the ids of these families: sf2.gen.<name> (generators),
#    sf2.mod.default.<n> (default modulators), sf2.mod.src.<name>,
#    sf2.mod.srctype.<name>, sf2.mod.transform.<name>, sf2.chunk.info.<ck>,
#    sf2.chunk.pdta.<ck> and sf2.sampletype.<name>. Their kind, section and facts
#    columns come from the spec text, and with `TUTTI_SF2_SPEC=<dir>` (a
#    directory holding the `pdftotext -layout` text, sfspec24.txt, or the PDF)
#    the gate holds them to it in both directions. `TUTTI_SF2_SPEC=<dir> cargo
#    xtask conformance-inventory sf2` regenerates those three columns in place,
#    keeps the hand columns of each row and appends a new id as a `todo` row
#    with no paraphrase (the gate refuses it until one is written). Without the
#    text the comparison is skipped and said so; `TUTTI_CONFORMANCE=require-all`
#    makes the absence a finding.
#  - Every other row is written by hand and checked by review. Its kind is the
#    conformance word of the sentence it paraphrases (must is required, should
#    recommended, may permitted; empty when the sentence has none). With the text
#    present the gate holds its section column to a section number the text has.
#
# Columns: id | side | maturity | kind | section | paraphrase | facts | na-kind | cite
#
# Sides: reader (what a file reader must do: tutti-sf2), player (what a
# synthesizer must do: tutti-soundfont) and rom-loader (the loader of a Silicon
# SoundFont ROM image, which neither crate is).
#
# Facts of the extracted rows (a name is a fact only when the text gives an
# integer): gen: num, min, max, def (from the summary table of section 8.1.3),
# inst_only=1 (the table's instrument-only mark), nonrt=1 (its non-real-time
# mark); mod.default: src and amtsrc (hex), type, p, d, cc, index, amount,
# transform; mod.src: index; mod.srctype and mod.transform and sampletype:
# value; chunk.pdta: recsize (bytes per record), minrecs; chunk.info: size (a
# fixed size) or maxlen (the string's byte limit).
#
# Ids of the hand-written rows, by area:
#   sf2.riff.*      RIFF structure and chunk order (sections 3, 4, 10.2)
#   sf2.info.*      the INFO list (5)
#   sf2.sdta.*      sample data and looping margins (6)
#   sf2.pdta.*      the pdta sub-chunks and their record rules (7)
#   sf2.genrule.*   generator kinds, placement and precedence (8.1, 8.5, 9.4)
#   sf2.mod.*       modulator sources, curves, the model and defaults (8.2 to 8.4, 9.5)
#   sf2.synth.*     the synthesis model (9.1 and the behaviour 8.1.2 describes)
#   sf2.midi.*      the MIDI functions a synthesizer answers (9.2)
#   sf2.units.*     parameter units (9.3)
#   sf2.nrpn.*      the SoundFont NRPN scheme (9.6)
#   sf2.error.*     error handling (10)
#   sf2.silicon.*   Silicon SoundFonts (11), N/A to both sides
# Writer-side rules (what a tool that writes a bank must produce) are not
# inventoried: no crate here writes SoundFont files.
#
