# VST 2.4 spec inventory. The names are the VST 2.4 SDK surface (aeffect.h,
# aeffectx.h), checked by review: no SDK header is in the repo and none was
# available to compare against, so the facts column is empty: a row's number is
# added when an SDK header is checked, never from memory or from a plug-in this
# repo builds. Paraphrases are in our own words.
#
# Columns: id | side | maturity | kind | section | paraphrase | facts | na-kind | cite
#
# Ids:
#   vst2.eff.<name>            dispatcher opcode the host sends the plug-in (side plugin)
#   vst2.audioMaster.<name>    opcode the plug-in sends the host's callback (side host)
#   vst2.field.<name>          an AEffect field (side plugin)
#   vst2.flag.<name>           an AEffect flags bit (side plugin)
#   vst2.entry.<name>          a module entry point (side plugin)
#   vst2.event.<name>          a VstEvent type (side core)
#   vst2.timeinfo.<name>       a VstTimeInfo flag the host sets (side host)
#   vst2.language.<name>, vst2.level.<name>, vst2.precision.<name>, vst2.automation.<name>,
#   vst2.category.<name>       constants of the opcodes that carry them
#   vst2.struct.<name>         a structure that crosses the dispatcher (side core)
#   vst2.cando.host.<s>        a canDo string the host answers to audioMasterCanDo (side host)
#   vst2.cando.plugin.<s>      a canDo string the plug-in answers to effCanDo (side plugin)
# na-kind deprecated rows cite the SDK header that marks the item deprecated
# (declared only without VST_FORCE_DEPRECATED, or under the 2.4 deprecation block).
