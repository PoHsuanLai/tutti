#
# Audio in a public API is generic over `tutti_buffers::Sample` (or `Float`). One
# `<key>  <reason>` row per site that is not; the gate fails on a site with no row, a
# row with no site and an unknown reason, so the list only shrinks as sites migrate.
#
# key     `<file>::<item>` for a free item, `<file>::<Owner>::<fn>` for a method (the
#         impl's type or the trait), `<file>::<Type>.<member>` for a field or enum
#         variant. No line numbers; same-keyed items share one row.
# reason  ffi          C ABI, IPC or wire; a comment at the site says why.
#         engine-f32   the engine is fixed at f32, pending its own migration row.
#         pending      not judged yet.
#         measured: <why>   kept after judging.
